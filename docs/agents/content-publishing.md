# 内容发布 Agent

输入：`zcms-blog-handoff-v1`；仅接受已完成人工审核的保存版本。
目标：Stage 的 blog 数据录入与回读验证。生产发布不在本版本范围内。

依据用户提供的 `zcms-upload-seo-blog.md` 整理字段和核对规范。用户明确选择服务 API 对接，因此接入前不执行浏览器 SSO 流程，不自行推断 Stage 地址或 API 富文本结构。

当前状态：可保存和导出交接草稿，等待 Stage API 合同与鉴权。此状态不表示文章已写入 ZCMS。

已实现的准备工作：
- 生成正文 HTML，保留真实公开数字引用和尾注；移除内部素材标记。
- SEO 标题使用官网后缀，正文与 SEO 字段分开；subContent 留空。
- 封面、分类、标签、作者头像和发布时间缺失时明确列出，不猜测 CMS 选项。
- 为每个文章审核版本保存独立交接记录；原资料和文章版本保留。

待接入后执行：字段映射、Stage 创建、按记录 ID 回读、核对全文及元数据、核对排序。只在回读及页面验证通过后标记验证成功。

详见 `/stage-publishing-api-checklist.md`。不得将 html 字符串未经确认直接作为自定义 JSON 富文本写入，不得伪造执行状态或外部记录 ID。
