# SEO 关键词文件分析

研究页提供两个入口：「使用 API 查询」和「上传关键词数据」。API 鉴权、网络或额度失败时，可保留种子词和研究范围切换至文件模式，失败的 API 任务保留在历史记录中。

## 客户操作

1. 切换「上传关键词数据」，下载 UTF-8 BOM CSV 空白模板，可使用 Excel 编辑后另存为 UTF-8 CSV。
2. 填写关键词、月均搜索量、数据来源。未知搜索量留空；真实零值填0。数据日期未知可留空，广告竞争度、指导价及币种选填；不能填搜索指数或估计区间。
3. 上传 CSV 或 JSON 数组（最大1.5 MB）。核对引擎、市场、设备和语言；也可统一填写文件缺少的来源、日期。
4. 点击校验，处理逐行错误、重复词冲突和范围不一致。预览前20个词，同时显示总行数、唯一词数、重复词数及实际保留范围；候选上限仍为200。
5. 勾选确认后调用当前账号已有模型，完成意图判断、词簇与页面方向分析，下载报告 Markdown、CSV 或完整 JSON。

## 行为与数据保证

- 上传路径不要求百度凭据、不使用百度的种子长度/市场限制，也不查询或补查百度。支持不同引擎的用户数据；API 方式依旧仅支持百度中国大陆。
- 原有 API 配置、查询流程及旧导入请求兼容。空文件、无效文件不自动回退到收费 API 查询。
- 相同数据的重复关键词只保留首次记录；重复词的指标或来源冲突时阻止提交。未知值与零值、数据日期与导入时间分别保留。
- 服务端独立重新校验，预览不写入任务或调用模型；创建明确上传模式任务需确认标记。文件模式任务不允许进入 API 查询阶段。
- 报告标明用户提供数据、文件名及导入摘要，不声称已通过 API 验证；缺少 SERP、SEO KD、趋势和本站排名时交付部分完成报告。
- 下载模板、预览、创建、运行和导出均沿用现有认证与账号隔离，写操作沿用同源检查。没有新增密钥要求。

验证使用 `npm run test:seo-keywords`、浏览器流程检查和 `npm run build`。接口测试覆盖无百度凭据的文件分析、预览无写入、确认要求、报告溯源、账号隔离；外部模型和百度响应均为固定测试数据，未消耗真实额度。
