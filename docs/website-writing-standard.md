# 官网内容写作规范（website-seo-v3）

整理日期：2026-11-11。由开发阶段阅读 Semrush 原文后提炼；内容写作 Agent 执行固定规范，不在每次写作时学习这些网页。当前仅开放“官网”平台，平台规则采用注册表管理。

## 规范与结构

1. 先明确目标读者、一个主关键词、搜索意图和选题价值。没有真实 SERP/关键词工具数据时，意图只能作为编辑判断，不编造搜索量或难度。
2. 按意图选择解释、操作步骤、比较或选择指南。先大纲、后正文：一个 H1；H2 回答核心问题；H3 支持对应 H2；每节有明确问题与依据。
3. 标题准确、简洁、体现价值。主关键词自然出现一次并尽量靠前；SEO Title 与 H1 主题一致，可以措辞不同。
4. 关键词自然分布于 Title、H1、开篇、相关小标题、正文和描述。辅助词服务于子问题，避免每段重复同一词组。
5. 不设“最佳密度”百分比。系统展示出现次数和分词占比，仅用于发现遗漏与过度重复；中文计数口径明确为词语分词。
6. 开篇直接回答问题，再解释范围、条件和步骤。采用短句、短段落、列表；有真实比较信息时使用表格。不虚构原创经验、调查、图片或专家引语。
7. TDK 独立提供：SEO Title、Meta Description、编辑用主/辅助关键词；另给建议 slug。描述用 1–2 句准确概括价值，不能承诺正文不支持的结果。
8. slug 简短、明确，以连字符分隔单词；无必要时不放日期或年份。编辑关键词列表不是排名保证。
9. 链接放在确有阅读价值的位置，锚文本清楚描述目标。引用公开研究、数字或案例时保留原始出处与时效，不自行编造站内路径。
10. CTA 与读者问题和资源相符，使用明确行动词，放在相关章节结束处或结尾。稀缺、免费、优惠、资格与时间承诺均须真实。
11. FAQ 只补充未解决的真实问题。格式、关键词或 FAQ 都不能保证排名、收录或 AI 引用。
12. 发布前检查意图、结构、表达、事实、引用、TDK、链接和时效；最终仍由编辑人工确认。

## 中文展示长度的处理

Semrush 标题专题给出约 550 像素、50–60 字符的展示参考。描述专题建议尽量控制在约 135 字符，而其 SEO 写作总览提到移动展示约 105 字符。这些建议来自不同页面及设备语境，不是统一硬性限制。

本版采用简洁、准确的中文 Title 和 1–2 句描述，不机械照搬拉丁字符配额。搜索引擎可能重写标题或摘要，实际展示应在发布端预览。

## 本工作台业务约束

以下约束来自用户需求，不能误称为 Semrush 的统一规定：

- 内部写作素材只用于组织内容；无法找到公开依据的相关事实删除；参考资料只列实际引用的公开来源。
- CTA 只从 Whitepaper、Events、Templates & Tools 中筛选，最多两个；没有合适资源就不添加。
- 活动必须有可核实、尚未到期的截止或结束时间；时效未知及已结束活动均排除。
- Agent 仅返回允许的 CTA ID 及已有章节标题；系统复核来源和时效后插入，不接受自行编造的 CTA 链接。
- 输出排版文稿、HTML 与 Markdown；复制和下载前重新检查来源与 CTA 状态。

## 输出模板

- 写作 Brief：主关键词、辅助词、读者、意图、主题价值。
- 发布字段：SEO Title、Meta Description、建议 slug、编辑关键词。
- H1 → 开篇直接回答 → 按意图组织 H2/H3 → 对应条件、限制与公开依据 → 可选 FAQ → 相关资源 CTA → 实际引用的公开参考资料。
