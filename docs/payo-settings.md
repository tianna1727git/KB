# Payo 设置入口与资料分类

设置统一从侧栏底部账号旁的齿轮进入，支持键盘焦点与悬停提示。设置页分为「服务设置」和「字段设置」，移除重复标题、工作台名前缀和发布占位面板；模型、MinerU、百度、Insights 及引用配置保留在服务设置。

字段设置沿用 PMI 的资料分类级联交互：字段标识为 `MaterialCategories`，层数为 1–6，支持名称、稳定选项值、父级、排序和删除。默认选项沿用 Payo 原有的八类，配置及历史引用按登录账号隔离。

分类配置保存后，同步供本地文件上传、网页提交、单条和批量分类修改、资料筛选、知识列表及知识检索使用。选择父级包含其下级；修改显示名称不改存储值。MCP 分类参数支持自定义值，由 API 按当前配置校验。

删除、重命名选项值或减少层数时，必须为仍有历史引用的值指定有效迁移目标。保存与迁移在一个 D1 事务中完成，使用配置版本检查和数据库触发器阻止过期保存、并发冲突及旧值重新写入。原文、文件键、资料内容版本和知识确认状态保留；只递增分类元数据版本，避免分类迁移使已确认知识失效。

首次打开字段设置不会改写历史数据；用户保存时才写配置及创建分类完整性触发器。无需单独运行数据库迁移脚本。更新仅限 Payo Stage 验收分支。

验证：`npm run test:material-categories`，已有 library-metadata、MinerU、MCP、SEO 集成测试和 knowledge-library 单元测试，以及 `npm run build`。浏览器检查覆盖齿轮入口、Tab 切换、两级分类添加保存、自定义分类上传选择及原有服务配置展示。所有外部接口均使用固定测试响应。

## 界面文案排版

中文、英文字母和数字在界面标签、按钮、提示和计数中相邻时不加空格，例如「Persona设置」「6个读者画像」「200MB」。英文词组和姓名保留词间空格，例如「Saved Insights」和「Alex Morgan」。源代码、用户原文和可复制的命令保持原样。
