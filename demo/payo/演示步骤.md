# Payo demo：160份Markdown → 知识库 → 拉美跨境101的多版本内容

当前左侧 demo 是实际工作流，不再展示预制的SWIFT申请知识和两版草稿。

## 1. 上传资料

在 demo 第一区块多选最多160份Markdown（.md / .markdown），每份非空、UTF-8、最大2 MB，点击“开始上传”。可分批补传。页面展示逐份处理进度、重复复用和失败记录；文件按内容指纹去重，现有160份资料可以直接选择继续解析，无需清空或重传。进入页面不会自动导入初始化资料。

列表支持关键词搜索、分页、选择全部搜索结果和下载原文。已上传成功的文件持久保存；中断后重新选择文件上传会复用已有内容。

## 2. 解析、切片、审核与入库

选择资料后点击“解析并切片”。当前demo采用Markdown标题、段落的结构切片，保留正文并校验逐字符覆盖，保留表格和风险提示。这一步不调用模型，不等于AI语义提炼或事实核验；AI语义整理继续通过资料库的知识整理Agent使用。

在第二区块选择资料，核对原文和切片，设置分类、用途、有效期和对外引用许可。普通切片核对后可批量确认；费用、条件、长章节、表格等重点条目逐条确认。仅标题切片不能直接入库，可通过完整校对页编辑或合并；不要编造正文。全部有效切片确认后来源进入可用知识范围，外部写作还要求来源允许对外引用且未过期、未停用、未被新版本替代。

同源已有语义知识复用，不追加规则切片或覆盖已有知识。操作只作用于当前登录账号，不清空原有资料。

## 3. 拉美跨境101写作Brief

选择主题“拉美跨境101”、平台“官网”，填写读者、写作Brief和规则，点击“保存Brief并检索知识”。系统检索已确认、有效且获引用许可的知识，展示前60条候选，选择1–20条作为Sources。此处是全文、关键词和同义表达检索，不声称向量召回或穷尽所有相关知识。

确认Sources后调用模型生成研究与大纲。用户可核对、调整大纲，再确认生成正文并运行检查，得到V1。缺少资料支持的信息列为待补充，不用预写草稿冒充实时生成。

## 4. Brief迭代与版本

完成首版后，修改同一任务上方的Brief并保存，系统保留V1快照，重新选择Sources和确认大纲，生成V2。重复操作可得到V3、V4等，不受旧工作流“自动修改最多两轮”限制；每次都是新Brief版本的完整生成。

各内容版本保留独立正文、对应Brief、规则和来源快照，支持查看和Markdown下载。手动改稿保存也会产生新版本，并等待检查。失败步骤不自动重试；旧版本保留，修复额度或配置后可继续当前步骤。刷新页面后在“继续已有demo文章任务”中打开进度。

研究、起草、检查分别调用模型并产生API用量。若未配置模型、额度不足或接口失败，系统明确停止；不会从当前Codex聊天自动取得模型调用能力，也不退回预制文章。关闭页面会停止后续步骤衔接，当前已经开始的服务端请求仍可能完成和计费。
