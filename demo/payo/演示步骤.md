# Payo MVP 演示：真实资料，Codex 预先准备结果

## 推荐：全部在 demo 菜单中演示

发布本次改动后，点击左侧 **demo**。整个流程在同一页四个区块内完成，不需要切换资料库、知识库和内容工作台：

1. **资料与 Markdown**：查看已有资料，展开原文或上传一个文本 PDF / XLSX 演示转换。
2. **知识整理与审核**：点击“载入预先整理结果并校验原文”，查看证据、逐条勾选后保存待确认知识。在页内设置资料分类、有效期及引用权限，并逐条确认知识；展示来源版本、知识修订和关联。
3. **Brief 与 Sources**：默认已填好匹配演示草稿的 Brief。点击创建新的 Brief，检索并确认对应的4条知识。也可以从下拉框继续已有演示任务。
4. **草稿与版本**：展开 V1/V2 预览，勾选导入确认并依次导入。查看历史版本并下载；现场改稿、保存为新版本。人工核对后可在页内确认交付。

本页所有写入均需要点击相应按钮；进入或刷新页面只读取已有状态，不重置数据。编辑草稿未保存时，切换菜单会提示。页面不会调用模型 API，不需手动上传演示 JSON。

演示包只通过服务端认证接口提供，当前账号需已保存对应 Swift 原文；不将资料正文打入前端静态脚本。

下面保留原有分菜单操作说明，供排查或单独使用导入功能。

## 范围

本演示不调用模型 API。知识和草稿由 Codex 阅读真实资料后预先整理；网站负责原文校验、人工审核、Sources 选择、版本保存和下载。不要介绍为现场自动生成。

资料库原有160份 Markdown 不重复上传。本演示只使用其中《02 【收款】如何使用Payoneer派安盈开通全球 Swift（电汇）收款账户.md》。没有连接或修改生产数据库。本地测试不能证明原站已更新。

## 演示一：资料库

展示已有160份资料和原文阅读。说明资料与已审核知识是两个阶段。

可用一份真实文本型 PDF 或 XLSX 展示转换及原文件下载。当前支持 PDF 文本层、DOCX、PPTX、XLSX、UTF-8 TXT。扫描 PDF、图片文字未接 OCR，不能承诺全部解析。Excel 保存表格值与公式，不重算公式或处理宏。不要用未知复杂文件作为唯一演示样本。

## 演示二：原文到知识

1. 进入“Codex 结果导入”，选择 `01-知识整理结果.json`。
2. 阅读预览并勾选导入确认，进入知识整理结果。标签应显示“引文匹配，待人工审核”，不是“模型复核通过”。
3. 展示4条知识、原文引文、遗漏说明；勾选已核对后保存待确认知识。
4. 打开来源页，核对分类、资料版本和适用范围。来源不提供生效日期，不编造生效日期。
5. 逐条对照确认4条知识；按实际审核结论设置是否允许对外引用。后续 Sources 演示需要所选条目已通过审核且获引用许可。
6. 到知识库展示来源V版本、知识R修订及共享产品实体的关联。关联不表示逻辑等价或因果。

重复导入同一个结果包只打开已有整理任务，不复制原文。原文变化时拒绝导入。若已有同源知识，保存整理结果可能形成待确认的新知识版本；旧知识不会在导入包时被覆盖。

## 演示三：Brief、Sources、草稿历史

在内容工作台新建 Brief，请逐字使用以下内容（也见 Brief.json）：

- 主题：申请 Payoneer SWIFT 收款账户前的准备清单
- 发布平台：官网
- 读者：准备申请 SWIFT 收款账户的跨境电商卖家
- 写作规则：仅依据所选 Sources；不承诺开户成功、到账时效或固定费率；材料要求以账户页面为准；每个事实段落保留来源编号。
- 补充需求：留空。

1. 检索 Sources，选择刚审核的4条知识，确认 Sources，停在研究阶段。不要点击需要模型额度的研究按钮。
2. 进入“Codex 结果导入”，选择 `02-草稿V1.json`，在下拉框选择刚建的任务。查看内容、勾选确认并导入。
3. 在文章任务展示正文、Sources 和“Codex 预先生成”标识；检查区明确显示未执行在线模型检查。
4. 返回导入页，选择 `03-草稿V2.json` 并选择同一任务，导入第二版。
5. 在“草稿版本”中分别查看、下载 V1 和 V2。V2 是预先准备的表格化编辑版本，不是线上自动重写。
6. 可现场修改一段正文并保存为 V3，再下载；保存不触发模型 API。离线版本仍需人工核对来源与规则，确认后才交付。

## 出错时

- 找不到来源：检查当前账号资料库是否有对应 Markdown；不要反复重复上传160份。
- Brief 不一致：核对主题、平台、读者、写作规则、补充需求。
- 来源不匹配：确保选择的是本次导入并审核的4条知识；若修改了知识正文，需让 Codex 按最新正文重新准备结果包，不要改指纹绕过校验。
- 知识不可引用：检查是否全部审核、来源是否停用/被替代、有效期、对外引用许可。
- 有其他品牌/法务规则：导入时保留当前有效规则快照，需人工确认草稿是否遵循它们，不声称预先草稿已自动应用。
