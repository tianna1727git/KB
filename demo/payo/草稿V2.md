# Payoneer SWIFT 收款账户申请准备清单

## Payoneer SWIFT 收款账户申请准备清单

准备申请时，先确认自己账号的开通要求，再核对账户类型、材料与银行验证状态。这些步骤来自现有操作资料，不能代替账号页面的实际要求。[S1][S2][S3][S4]

| 准备事项 | 建议核对的内容 | 依据 |
| --- | --- | --- |
| 开通要求 | 登录“收款账户”，通过“更多国家”查看对应国家或地区的要求；必要时咨询客户经理。 | [S1] |
| 账户类型 | 选择 SWIFT（电汇）收款账户，再继续下一步。 | [S2] |
| 身份与业务材料 | 按系统要求上传；资料中的问卷调查和带照片身份证明仅为页面列举，并非统一材料清单。 | [S3] |
| 银行账户验证 | 检查是否仍需提供额外信息，并以自己账号的验证提示为准。 | [S4] |

### 材料清单为什么不能照搬？

资料要求在系统提示身份信息和文件验证时，按页面要求上传相关材料并等待审核。因此，准备材料应以申请账号的实际页面为依据，不应把示例中的材料名称理解为固定、完整的要求。[S3]

### 提交前的最后检查

回到账号确认开通要求、账户类型及银行验证状态。本文不承诺审批结果、处理时效或费用；如具体要求不清楚，可联系客户经理获取说明。[S1][S2][S4]
